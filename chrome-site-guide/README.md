# افهم الموقع — Site Guide

إضافة Chrome Manifest V3 بلوحة جانبية عربية. تحلل العناصر الظاهرة عند الضغط فقط، وتعرض العناوين والحقول والأزرار والروابط، مع مؤشر لواجهات Odoo وخريطة محلية لآخر 100 صفحة محللة وتصدير JSON.

## التثبيت والاستخدام

1. فك ضغط `site-guide-chrome.zip` في مجلد ثابت على جهازك.
2. افتح `chrome://extensions` وفعّل **Developer mode / وضع المطوّر**.
3. اختر **Load unpacked / تحميل إضافة غير مضغوطة** وحدد المجلد الذي يحتوي على `manifest.json`.
4. افتح الموقع وسجّل الدخول بنفسك، ثم اضغط أيقونة الإضافة واختر **حلّل الصفحة الحالية**.
5. انتقل للصفحات التي تريد فهمها واضغط التحليل لكل صفحة. اضغط **تصدير التقرير** لتنزيل خريطة الموقع ومشاركتها بعد مراجعتها.

تحتاج Chrome 116 أو أحدث. إذا انتقلت إلى موقع مختلف، اضغط أيقونة الإضافة فيه لمنح الإذن. تحميل الإضافة غير المضغوطة هو طريقة التثبيت الحالية؛ لم تُنشر في متجر Chrome.

## الخصوصية والحدود

- لا خدمات خارجية أو ذكاء اصطناعي خارجي أو تتبّع أو تنفيذ نقرات وتغييرات على الموقع.
- لا قراءة لقيم الحقول. تستبعد الحقول التي تشير أسماؤها/أنواعها إلى كلمات مرور أو PIN أو OTP أو أسرار؛ لا يمكن ضمان اكتشاف كل تسمية غير معتادة.
- أسماء العناصر والعناوين ومسارات الروابط قد تتضمن معلومات خاصة. تُحفظ محليًا في ملف مستخدم Chrome حتى تمسح الخريطة أو تزيل الإضافة؛ راجع التقرير قبل مشاركته.
- تُزال query parameters وURL fragments، لكن أسماء الصفحات والمسارات نفسها قد تحتوي على معرّفات. توحيد المسارات يعني أن صفحات تختلف بالـquery أو hash تظهر كصفحة واحدة في الخريطة.
- التحليل وصفي حسب العناصر الموجودة، ولا يثبت وظائف الخادم أو صلاحيات المستخدم. لا يشمل الإطارات الداخلية أو Shadow DOM أو الصفحات غير المحملة.
- كشف Odoo استدلال من علامات الواجهة؛ لا يستخرج الإصدار أو الموديل أو معلومات الجلسة.
- لا دعم لصفحات Chrome الداخلية أو المتجر أو PDF أو التطبيقات الأصلية.

## التحقق

اختبارات Chromium عبر Playwright لصفحات تجريبية: استخراج العناصر، استبعاد الحقول والقيم الحساسة والمخفية، تنظيف الروابط، عرض اللوحة، الحفظ، منع التكرار، التصدير، المسح وأخطاء الإذن.

```sh
node chrome-site-guide/tests/smoke.cjs
```

تحتاج الاختبارات Playwright وChromium (المسار الحالي `/usr/bin/chromium`). تستخدم الاختبارات واجهات Chrome وهمية للوحة؛ لم يتم التحقق من تحميل الإضافة الفعلي أو تسجيل الدخول إلى Appraid في البيئة الحالية.
